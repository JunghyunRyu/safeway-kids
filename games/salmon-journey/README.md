# 연어의 여행 🐟 (Salmon Journey)

연어의 **생애 주기**를 따라가는 아주 간단한 세로 방향 모바일 웹 게임.
민물에서 태어난 연어가 바다로 내려가 자란 뒤, 다시 태어난 강으로 거슬러 올라가
알을 낳기까지의 여정을 담았다. 외부 에셋·라이브러리 없이 **단일 HTML 파일**(`index.html`)로 동작한다.

## 생애 단계 (3 stage)
| 단계 | 무대 | 포식자/장애물 | 연어 모습 |
|------|------|----------------|-----------|
| ① 강 하류 | 민물(초록) — 바다로! | 🐟 큰 물고기, 🐦 왜가리, 🪨 바위 | 작은 은빛 치어 |
| ② 넓은 바다 | 깊은 바다(파랑) — 성장! | 🦈 상어, 🦭 바다표범, 🍣 초밥 접시(사람) | 은빛 성어 |
| ③ 강 상류 회귀 | 회귀하는 강(청록) — 산란! | 🐻 곰, 🎣 낚시꾼, 🦅 독수리, 🪨 바위 | 붉은 산란 연어 |

상류 산란장(🏁)에 도착하면 **산란 미니게임** — 알을 노리는 포식자가 다가올 때
**탭하면 방어막(🛡️)이 "딱!"** 생겨 막는다(점프 대신). 많이 막고 알이 남을수록 보너스.
그 뒤 알에서 **새끼가 부화해 다시 바다로** —
세대(generation)가 +1 되고 작은 치어로 ①단계부터 다시 시작한다.
이렇게 **생명의 순환이 무한히 이어지며**, 포식자에게 잡히면 끝.
점수는 누적 이동 거리(m), 함께 **몇 세대까지 이었는지**를 기록한다.

## 플레이 방법
- 연어는 화면 아래쪽에서 **위로 거슬러** 헤엄친다. 포식자와 먹이는 위에서 내려온다.
- 📱 모바일: 화면을 **좌/우로 스와이프**해 레인(세로 칸) 이동
- 💻 데스크톱: **←/→** 또는 **A/D** (시작/재시작은 Space/Enter)
- 🍤 위에서 내려오는 **먹이**를 먹으면 보너스 점수 + 더 빨리 성장
- 거슬러 올라간 거리(m)가 점수. 시간이 지날수록 빨라진다.
- 최고 기록은 브라우저(localStorage)에 저장된다.

## 실행
설치 불필요. `index.html`을 브라우저로 열면 끝.

로컬 서버로 열고 싶다면:
```bash
cd games/salmon-journey
python3 -m http.server 8080
# 브라우저에서 http://localhost:8080
```

## 구현 메모
- HTML5 Canvas + requestAnimationFrame 루프 (세로 스크롤)
- 4개 세로 레인 기반, 단계별로 포식자 풀·배경색·연어 크기/색이 전환된다
- 연어는 그리기 기준(오른쪽)을 -90° 회전해 위를 향하게 렌더
- 연어/장애물/먹이는 Canvas 도형 + 이모지로 그려 별도 이미지 파일 없음
- 배경색은 단계 전환 시 RGB 보간으로 부드럽게 바뀐다
- DPR 대응(고해상도 화면 선명), `viewport-fit=cover`로 노치 대응
