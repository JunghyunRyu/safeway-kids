## 1. 신청사 개요

| 신청 기업명 | SAFEWAY KIDS (세이프웨이 키즈) / 법인명 미정 |
| --- | --- |
| 서비스명 | AI 기반 어린이 통학 셔틀버스 공유 플랫폼 서비스 |
| 서비스 개요 | AI 컴퓨터 비전(안면인식, 이상행동 감지, 잔류인원 감지) 및다중 경유지 배차 최적화(VRP-TW) 기술을 통합하여,학원/유치원 간 어린이 통학차량을 공유하는 모빌리티 플랫폼 |
| 핵심 기술 | ① 엣지 AI: YOLOv8 + DeepSort + MediaPipe (차량 내 이상행동/잔류인원 감지)② 안면인식: FaceNet + Anti-spoofing (비접촉 승하차 인증)③ VRP-TW: Google OR-Tools 기반 다중경유지 배차 최적화④ 사각지대 감지: LiDAR + 컴퓨터비전 융합 외부 보행자 추적 |
| 신청 유형 | 실증을 위한 규제특례 (정보통신융합법 제38조의 2) |
| 희망 실증 기간 | 2년 (법령 정비 미완료 시 1회 연장 신청 예정, 최대 4년) |
| 희망 실증 지역 | 서울특별시 특정 1개 구 (초기 파일럿, 추후 확대) |
| 희망 실증 규모 | 차량 10~20대 / 학원·유치원 20~50곳 / 원생 200~500명 |

## 2. 규제 충돌 사항 및 신청 사유

본 서비스는 아래의 현행 법령으로 인해 허가 등을 신청하는 것이 불가능하거나, 기준을 적용하는 것이 불명확한 상황에 해당한다.

### 2.1 규제 충돌 ①: 여객자동차 운수사업법 제81조

| 충돌 법령 | 여객자동차 운수사업법 제81조 (자가용 유상운송 금지) |
| --- | --- |
| 충돌 내용 | 교육목적 운행은 예외적으로 허용되나,학원·유치원이 직접 소유(공동소유)한 차량만 허용됨.제3자 플랫폼이 소유한 차량으로 운송계약을 체결하는 것은 불가능. |
| 선례 참조 | (주)스쿨버스 — 2023년 3월 ICT 샌드박스 실증특례 승인→ 신청기업이 직접 차량 구매 + 기사 직접 고용 모델로 특례 승인 |

### 2.2 규제 충돌 ②: 도로교통법 제52조

| 충돌 법령 | 도로교통법 제52조 및 시행령 제31조 (통학버스 명의 요건) |
| --- | --- |
| 충돌 내용 | 어린이 통학버스는 교육시설의 장 명의로 등록되거나,시설의 장이 전세버스사업자와 직접 운송계약을 체결한 차량이어야 함.플랫폼이 중개하는 다대다(N:N) 계약 구조는 현행법 해석상 불명확. |

### 2.3 규제 충돌 ③: 세림이법 (동승보호자 의무)

세림이법에 따라 어린이 통학버스는 운전자 외 동승 보호자가 반드시 탑승해야 한다. 플랫폼은 기사 배치뿐 아니라 단기 동승 보호자 파트타이머의 실시간 매칭 기능을 포함하며, 이는 긱 이코노미 모델로 운영된다. 실증 기간 동안 동승보호자 의무를 100% 준수하며, AI 모니터링은 이를 보완하는 추가 안전 계층으로 운영된다.

| 핵심 신청 사유 요약여객자동차법 제81조와 도로교통법 제52조의 차량 명의/소유 요건이, AI 기반 공유 플랫폼 모델에 적용하기에 불명확하고 불합리하여, 플랫폼이 중개하는 N:N 전자계약 구조의 합법성을 실증을 통해 검증하고자 함. 동시에, 엣지 AI 기반 차량 내 안전 모니터링 기술이 기존 세림이법의 동승보호자 의무를 보완하는 기술적 안전망으로서 유효함을 실증하고자 함. |

## 3. 기존 선례 대비 기술적 차별화

(주)스쿨버스가 2023년 통학차량 분야 최초로 실증특례를 승인받은 바 있으며, SAFEWAY KIDS는 해당 선례를 기반으로 하되 다음의 기술적 차별화를 통해 별도의 실증 범위를 신청한다.

| 비교 항목 | (주)스쿨버스 (기승인) | SAFEWAY KIDS (신규 신청) |
| --- | --- | --- |
| 사업 모델 | 직접 차량 구매 + 기사 직접 고용 | AI 기반 공유 플랫폼 (N:N 전자계약 중개) |
| 차량 내 안전 기술 | GPS 위치추적 + 안전운전지수 | Edge AI (이상행동감지, 잔류인원감지, 안면인식) |
| 승하차 관리 | 앱 기반 수동 체크인/체크아웃 | AI 안면인식 자동 인증 (95%+ 인식률) |
| 배차 최적화 | 수동 노선 설정 | VRP-TW 알고리즘 기반 자동 최적화 |
| 사각지대 감지 | 해당 없음 | LiDAR + CV 융합 외부 보행자 추적 |
| 동승보호자 관리 | 교육기관 자체 확보 | 플랫폼 내 긱 이코노미 실시간 매칭 |

| 패스트트랙 적용 가능성2025년 4월 개정 정보통신융합법에 따라, 이미 처리된 실증특례 과제와 동종·유사한 경우 패스트트랙이 적용되어 관계부처 협의 기간이 30일에서 15일로 단축됩니다. 다만 SAFEWAY KIDS는 기존 스쿨버스 대비 AI 안전감지, 공유플랫폼 모델 등 기술적 차별화가 명확하므로, 동종·유사가 아닌 별도 신규 실증특례로 신청하는 것을 권장합니다. |
| --- |

## 4. 안전 조치 계획

실증특례 승인 시 국민의 생명·안전에 대한 우려를 방지하기 위해 다음의 안전 조치를 수립한다.

| 안전 조치 항목 | 세부 이행 계획 |
| --- | --- |
| 동승보호자 의무 준수 | 세림이법에 따른 동승보호자 탑승을 100% 준수. AI 모니터링은 대체가 아닌 보완 계층으로 운영. 플랫폼 내 긱 이코노미 매칭으로 보호자 인력풀 상시 확보. |
| 책임보험 가입 | 실증 개시 전 보험업법에 따른 종합보험 가입 완료. 사고 발생 시 피해자가 아닌 사업자에게 고의·과실 입증책임 전환 조건 수용. |
| 차량 안전 기준 | 모든 차량 황색 도색 + 보호표지 부착. 15인승 이하 소형승합차 사용. 차량 연식 3년 이내 제한. |
| 운전자 검증 | 범죄경력 조회 + 운전경력 5년 이상 + 법정 안전교육 이수 완료 확인 후 배치. 플랫폼 내 디지털 증빙 보관. |
| AI 안전 모니터링 | 엣지 AI가 차량 내 이상행동·잔류인원을 실시간 감지하여 기사+관제센터+학부모에게 즉시 경보 송출. 시동 OFF 후 잔류인원 감지 시 문 잠금 해제 불가. |
| 개인정보보호 | 14세 미만 아동 대상으로 법정대리인 동의 프로세스 구현. 안면인식 생체데이터 AES-256 암호화 + 추론 후 즉시 휘발 처리. |
| 사고 대응 프로토콜 | 안전사고 발생 시 30분 이내 관계기관 보고 + 학부모 전원 긴급 알림. 월별 안전 보고서를 과기정통부에 제출. |

## 5. 기대 효과 및 사회적 가치

### 5.1 학생·학부모 편익성 제고

AI 안면인식으로 승하차 누락을 원천 차단하여 어린이 안전사고 예방

실시간 차량 위치 + 초단위 도착 예측으로 학부모 불안감 해소

앱 기반 원터치 스케줄 변경으로 맞벌이 가구 육아 스트레스 대폭 감소

### 5.2 교육기관 경제적 효익

개별 학원의 차량 유지보수비, 기사 채용 리소스 등 고정비 최대 30% 절감 (셔틀타요 실증 기준)

학원이 본연의 교육 업무에 집중할 수 있는 환경 조성

공유 모델을 통한 공차율 감소로 통학 물류 전반의 효율성 향상

### 5.3 사회적 가치 창출

그동안 블랙박스 영역이던 통학차량 내부를 '데이터화'하여 시스템적 안전망 구축

AI가 규정 위반 자체를 원천적으로 불가능하게 만드는 디지털 컴플라이언스 인프라 역할

동승보호자 긱 이코노미 매칭으로 지역사회 일자리 창출 (주부, 시니어 인력 활용)
