# 변호사 미팅 시연 — Cheat Sheet

**일시**: 2026-05-07 (오늘)
**대상**: 이의림 변호사 (대한상공회의소)
**목적**: SafeWay Kids ICT 샌드박스 v2.1 cross-check + 양길모 의견서 검토

---

## 0. 미팅 시작 5~10분 전 (필수 사전 준비)

```
1. demo\launcher.bat 더블클릭
2. 메뉴에서 [6] (한번에 모두 시작) 선택
3. 4개 창이 다 뜨면 — 백엔드 / 웹 / 사이트 / Edge AI
4. 웹 대시보드(5173)에서 플랫폼 관리자 로그인 → /seed → 시드 데이터 생성 1회
5. 노트북 디스플레이를 미러링/외부모니터로 설정
6. 마이크/스피커 — Edge AI 음성 경고 들리는지 사전 테스트
7. 노트북 웹캠이 가려져 있지 않은지 확인
```

## 1. 변호사 요청 → 즉시 시연 매핑

### A. "AI가 정말로 어린이를 인식하나요?"
| 데모 | 키 |
|---|---|
| **화면인식 (Edge AI)** | 런처 [1] → http://localhost:7860 |

**시연 순서**:
1. ① 탭 → "얼굴 등록" 클릭 → 동의 체크 → 본인 얼굴 등록
2. 웹캠 앞에서: 초록색 박스 + "탑승확인 (95%)" 표시 보여주기
3. 시연 멘트:
   - "보호자 동의 후에만 등록됩니다"
   - "원본 이미지는 저장하지 않고 512차원 특징 벡터만 암호화 저장합니다"
   - "추론 시간 100ms 이하 — 차량 내 Jetson에서 실시간 처리"

### B. "졸음/이상 행동은 어떻게 감지하나요?"
| 데모 | 키 |
|---|---|
| **이상행동 감지** | 런처 [1] → 상단 ② 탭 |

**시연 순서**:
1. 의자에 앉으면 초록색 "Normal"
2. 천천히 일어서서 3초 유지 → 빨간색 "STANDING" + 음성 경고
3. 시연 멘트:
   - "2초 이상 지속될 때만 경고 — 거짓 경고 5% 이하"
   - "정차 중에는 일어서도 경고하지 않습니다 (운행 모드 구분)"
   - "운전기사 방해 최소화 위해 음성 경고만 사용"

### C. "세림이법 잔류 인원 감지는?"
| 데모 | 키 |
|---|---|
| **잔류 감지** | 런처 [1] → 상단 ③ 탭 |

**시연 순서**:
1. 웹캠 앞에 사람 있는 상태에서 [시동 OFF] 클릭 → 빨간 "잔류 인원 감지!"
2. 비켜서서 다시 [시동 OFF] → "ALL CLEAR" 초록색
3. 시연 멘트:
   - "시동 OFF 시 5프레임 연속 분석 — 차량 구석 숨은 아이도 감지"
   - "감지 시 관리자 + 학부모 동시 알림"

### D. "차량 사각지대 어린이 감지는?"
| 데모 | 키 |
|---|---|
| **사각지대 시뮬레이션** | 런처 [1] → 상단 ④ 탭 |

**시연 순서**:
1. 시나리오 드롭다운 → "후방 접근" → [▶ 재생]
2. 가상 어린이가 차량에 접근 — 거리에 따라 노란 → 주황 → 빨강 단계
3. [마우스 모드] 버튼으로 직접 어린이 위치 드래그 가능
4. 시연 멘트:
   - "VLP-16 LiDAR 360도 + 초음파 12개 시뮬레이션"
   - "센서 노이즈(±3cm) 드롭아웃(2%) 반영한 물리 기반 시뮬"
   - "두 센서를 7:3로 융합 — 오탐 감소"
   - "실제 하드웨어 장착 시 동일 알고리즘 작동"

### E. "GPS는 어떻게 추적되나요?"
| 데모 | 키 |
|---|---|
| **실시간 관제 + GPS 시뮬** | 런처 [3] + [5] |

**시연 순서**:
1. [3] 웹 대시보드 → 플랫폼 관리자 로그인 → `/map`
2. [5] GPS 시뮬레이터 시작 (3대 차량, 5초 간격)
3. 지도에서 차량 마커가 5초마다 움직이는 것을 보여줌
4. 시연 멘트:
   - "실제 차량의 GPS 모듈 패킷과 동일한 형식으로 백엔드에 전송됩니다"
   - "WebSocket으로 학부모 앱과 관제 화면이 동시 갱신됩니다"
   - "위치정보는 운행 종료 후 30일 보관, 그 이후 자동 익명화"

### F. "학부모 앱은 어떻게 생겼나요?"
| 데모 | 키 |
|---|---|
| **모바일 화면** | (사진) `c14-demo-*.png` 8장 + Expo Go QR (옵션) |

**시연 순서 (사진 사용)**:
1. 노트북 파일 탐색기에서 `safeway_kids` 루트 폴더 열기
2. `c14-demo-1-search-results.png` ~ `c14-demo-9-livetrack-final.png` 순서로 보여줌
3. 시연 멘트:
   - "탑승 시 학부모 앱에 푸시 알림 + 위치 실시간 표시"
   - "도착 시 자동으로 알림 종료"

**시연 순서 (Expo Go 직접, 시간 여유 있을 때만)**:

## 2. 변호사가 자주 하는 질문 + 사전 답변

| 질문 | 데모 매핑 | 핵심 답변 |
|---|---|---|
| "AI 학습에 어린이 데이터를 쓰나요?" | A 화면인식 | "원본 이미지는 저장 안 함. 512차원 벡터만 AES-GCM 암호화 저장" |
| "위치정보 보유 기간?" | E + G | "운행 종료 후 30일, 이후 자동 익명화" |
| "고영향 AI에 해당하나요?" | — | "양길모 변호사 자문 결과 미해당. 다만 자발적 거버넌스 이중 트랙으로 대응 (v2.1 §4.6)" |
| "사고 시 책임 소재?" | (음성으로) | "운수사업자 = 1차 운송계약자, 학원 = 위탁자, 플랫폼 = 중개자. 양길모 자문 Q1 답변" |
| "개보법 §29 안전조치 의무?" | A + Swagger | "Student.name AES-GCM 암호화, name_hash 인덱스, OTP 6자리 만료 5분, 감사로그 100% 기록" |
| "정통망법 임시조치?" | — | "양길모 자문 Q3 — 통신매개자가 아닌 운송 중개자라 임시조치 의무 면제" |
| "사용자 동의 철회 시 데이터 삭제?" | G + Swagger | "철회 즉시 30일 안에 hard delete, 법정보관 의무 자료(세금계산서 등)만 별도 보관" |

## 3. 미팅 종료 후

```
1. 런처 [9] (모든 데모 프로세스 종료)
2. 노트북 셧다운 전에 cmd 창 4개가 다 닫혔는지 확인
3. 변호사가 추가 자료 요청한 것을 메모 → STATE.md "Blockers" 업데이트
4. /session-end 로 핸드오프 패킷 작성
```

## 4. 비상 대응

| 증상 | 즉시 대응 |
|---|---|
| Edge AI 웹캠 안 잡힘 | Zoom/Teams 종료 → start.bat 재실행 |
| 웹 대시보드 빈 화면 | 백엔드(8000) 살아있는지 → /healthz 확인 → [9]로 정리 후 [6] 재시작 |
| GPS 시뮬레이터 401 | 시드 데이터 안 들어감 → 웹 /seed 메뉴에서 생성 |
| 포트 충돌 | [9] 한 번 실행 후 [6] 재시작 |
| 변호사가 폰으로 직접 보고 싶다 | 노트북 IP 확인 후 같은 와이파이에서 http://노트북IP:5173 접속 |
