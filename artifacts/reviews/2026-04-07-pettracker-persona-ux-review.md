## 페르소나별 이탈 가능 지점 요약

```
박지은(보호자):  [예약] 날짜 선택 없음 → 이탈
                [산책 중] LiveTrack 작동 안 함 → 신뢰 붕괴 → 이탈

김민준(산책사):  [산책 시작] 어떤 개인지 모름 → 혼란 → 이탈
                [정산] 수수료 불명확 → 불신 → 이탈

이수진(비기술):  [검색] YYYY-MM-DD 입력 → 즉시 이탈
                [온보딩] 강아지만 나옴 → "고양이 안 되나?" → 이탈

최동현(전문):    [산책] demo 상태 앱 → 전문가 신뢰 상실 → 즉시 이탈
                [수익] 수수료 미표시 → Rover 복귀 → 이탈
```
