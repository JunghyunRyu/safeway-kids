## 페르소나별 이탈 가능 지점

```
한서연(보호자):  [모니터링] MOCK 데이터 + 허위 경보 → 신뢰 붕괴 → 이탈
                [예약] 날짜 선택 없음 → 마찰 → 이탈

정유나(신규):    [자격 등록] 절차 화면 없음 → "이거 뭐야" → 이탈
                [정산] 수수료 불명, 내역 없음 → 불신 → 이탈

김태호(비기술):  [자녀 등록] YYYY-MM-DD 입력 → 즉시 이탈
                [동의서] 법률 용어 → 공포/혼란 → 이탈

박미영(전문):    [정산] 수수료 20% 숨김 + 내역 없음 → 맘시터 복귀
                [리뷰] 답변/이의제기 불가 → 이탈
```
