## 0. LOI 사용 정책 (사용자 발송 전 확인)

### 0-1. LOI는 무엇인가
**Letter of Intent (의향서)** — 법적 구속력 없는 자문 의향 표명. 자문진은 PT에 대해 자문할 의지를 표명하지만 보수·지분·시간·계약 의무는 발생하지 않음. 정식 자문 계약은 별도 합의 시점에 발효.

### 0-2. 평가위원에게 LOI가 의미하는 것
- ✓ "자문 가능성·전문가 검증" 신호 — 5명 자문진 확보 = 사용자가 외주 전문성을 사전 확보
- ✓ "1인 창업가 위험 분산 능력" 검증 — 멘토 페르소나(P5) 가점 영역
- ✓ "도메인 신뢰성" 검증 — 산업 페르소나(P3) 가점 영역
- ❌ "자문진의 자금 출자 약정"은 아님 — 자금 계획표에는 영향 없음
- ❌ 정식 자문 계약 = 별도 시점, 본 LOI로 의무 발생 없음

### 0-3. 이메일 발송 순서 (5/9 마감 기준)

| D-Day | 발송일 | 수신자 | 비고 |
|---|---|---|---|
| 4/30 (D-9) | 1차 발송 | ① 수의사 ② 이의림 변호사 ③ UX 디자이너 ④ 도메인 선배 창업가 | 1차 4명 동시 발송 |

| 5/9 (D-Day) | LOI 회수 마감 | 신청서 §팀역량에 통합 |

### 0-4. 회신율 가정 (보수 추정)
- 5명 발송 → 5/9까지 **3명 회신 가정** (60%)
- 회신 3명 = strong-go gate 충족 (5/8 D-7 게이트 = LOI 3건 이상)
- 회신 5명 = best case → 신청서 §팀역량 만점 가까이

## 5. 신청서 §팀역량 raw input (5/9 본문 v1 작성 시 인용)

> 회신 결과에 따라 5/9 시점 본문에 인용할 narrative.

### 시나리오 A: 5명 모두 회신 (best case)
```
[팀역량 — 자문진]
1인 창업가의 한계를 보완하기 위해 다음 5개 영역의 자문진 LOI를 사전 확보
하였다. 본 자문진은 모두 정식 자문 계약 전 단계로, PetTracker의 도메인
신뢰성·법률 리스크·UX·시장 검증·운영 경험에 대한 외부 검증 신호다.

(1) 임상 수의학: [수의사 이름], [소속] — 산책 응급 / 견종별 가이드
(2) 펫 마케팅: [펫마케팅 전문가], [소속] — 1인 가구 페르소나 / 캠페인 검토
(3) IT·플랫폼 법무: 이의림 변호사 (대한상공회의소 자문 트랙) — 약관 / 사고
    책임 / 개인정보·위치정보처리방침
(4) UX 디자인: [UX 디자이너], [소속] — 보호자·펫시터 양면 UX
(5) 1인 창업 운영: [선배 창업가] (전 [회사]) — 출시 burn rate / 락인 / 번아웃

각 자문 의향서 (LOI)는 신청서 별첨 불가하므로 신청자 보관, 평가 시
별도 요청 시 즉시 제출 가능.
```

### 시나리오 B: 3~4명 회신 (strong-go gate 충족)
```
[팀역량 — 자문진]
다음 [N]개 영역의 자문진 LOI를 확보하였다.
[회신자 N명만 인용]

기타 영역(예: 미회신 영역)은 출시 후 정식 자문 계약 시점에 보강한다.
```

### 시나리오 C: 1~2명 회신 (5/8 D-7 strong-go gate 미달)
```
[팀역량 — 자문진]
[회신자 1~2명만 인용] + [출시 후 6개월 자문진 5명 확보 plan].

5/8 strong-go gate 미달 시 다음 회차 (K-Startup 초기창업패키지) 전환 결정 가능.
```

### 시나리오 D: 0명 회신 (no-go)
신청서 §팀역량에 자문진 영역 미기재. 1인 창업가의 출시 후 실측 데이터로
검증 narrative로 대체. **5/8 strong-go gate 미달 → 다음 회차 전환 결정 권장**.
