# PT 5/8 D-7 게이트 — 5/5~5/8 Hourly Critical Path

**문서 분류**: 의사결정 외주 도구 (1인 창업가 burnout 방지)
**작성일**: 2026-05-05
**적용 기간**: 5/5 화 ~ 5/8 금 18:00 게이트 (4일, 96시간)
**목표 회수치 (5/8 18:00 게이트)**: LOI ≥3건 + 가입자 ≥30명 → strong-go 통과
**사용 방법**: 매일 아침 첫 작업 = 이 문서 열기 → 그날 행 따라 실행 → 끝
**권장**: 이 문서를 카카오톡 본인 채팅에 핀 + 매일 아침 알림

## 0. 4일 압축 — 핵심 원칙

`★ 의사결정 외주 원칙`
1. **시간표가 결정을 대신한다** — "다음에 뭘 하지?" 묻지 말고 시간표 행만 본다
2. **모든 결정은 어제 끝났다** — 시간표 변경은 critical 한 신호 발생 시에만
3. **slot이 비어도 OK** — 모든 시간을 채우지 않음, "여백"도 계획의 일부
4. **결과만 기록한다** — 시간표 옆 "실측" 칸에 1줄 (LOI 회수 / 가입자 N)

**오늘 (5/5)이 가장 중요한 이유**: D-3은 **마지막 인프라 셋업 + outbound 트리거** 시점. 오늘 셋업 미뤄지면 5/6~5/8 outbound는 LIVE URL 없이 진행 → conversion -50%.

```

├─ YES → STRONG-GO
│   └─ 5/9 신청서 v2 placeholder 6건 inject 진입
```

## 6. Risk + Escalation Plan

`★ Insight: 1인 창업가 critical path의 4가지 fail mode`
1. **인프라 셋업 막힘** (Vercel·DNS) → 5/5 18시까지 미해결 시 즉시 알리기
2. **친척 응답 zero** → 5/6 정오까지 무응답 시 다른 친척 1명 추가 카톡
3. **카톡 친구 outbound 중단** → 50명 다 발송 못 해도 25명만 해도 게이트 가능
4. **번아웃** → 4일 96시간 중 14h만 active, 나머지는 회복 시간

| Risk | 신호 | Escalation |
|---|---|---|
| Vercel 5/5 셋업 실패 | 18시까지 lunenlabs.vercel.app 미작동 | 즉시 사용자 알림 + 가이드 §2~§4 재확인 |
| DNS propagation 24h 초과 | 5/6 18시까지 lunenlabs.com 미작동 | Namecheap 설정 점검 (Parking Page 비활성화 여부) |
| 친척 응답 zero | 5/6 정오까지 무응답 | 다른 친척·친구 1명 카톡 |
| 카톡 친구 응답률 <20% | 5/7 18시까지 응답 5건 미만 | 메시지 어조 점검 (사업 부탁 어조 → 일상 대화 어조) |
| 5/8 16:00 LOI <3 | 게이트 D-2시간 | conditional-go path 진입 (운영기관 사전 문의) |
