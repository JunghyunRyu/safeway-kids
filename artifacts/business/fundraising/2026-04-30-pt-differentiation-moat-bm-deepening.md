## 영역 1: 기존 앱들과 다른 점 (차별화 강화)

### 1-1. 메타-차별화 3 Layer

단순 기능 목록으로는 "그래서 진짜 다른 게 뭔가요?" 질문을 넘기지 못한다. PT 차별화를 3개 레이어로 재구성한다.

**Layer A — 기능 차별화 (Feature Differentiation)**

경쟁사 5개사와 PT 비교 시 즉시 보이는 기능 차이. 와요가 GPS + LIVE 영상 보유하므로 GPS 단독은 차별화가 아니다. PT 기능 차별화 핵심 2건:
- (1) 사고 신고 의무 자동화 — 5개사 모두 수동 알림에 의존, 사고 기록 자동 보전 기능 없음. PT는 사고 버튼 → 119 알림 + 보호자 SMS + 가까운 동물병원 GPS 안내 + 타임스탬프 기록 4단계를 1회 탭으로 처리
- (2) AI 산책 리포트 — LIVE 영상(와요)이 보호자가 능동 시청해야 하는 "push" UX라면, PT의 자동 리포트는 산책 종료 후 보호자 받은편지함에 도달하는 "pull" UX. 두 가지는 충돌하지 않으며 다른 segment를 잡음

**Layer B — 데이터·운영 차별화 (Data & Operational Moat)**

기능은 카피 가능. 진짜 차별화는 PT가 운영하면서 자동으로 쌓이는 데이터와 이것이 V1.1·V1.2 알고리즘에 먹히는 구조다. 도그메이트는 15만 건 돌봄 기록을 보유하지만 AI 추론에 투입한 증거가 없다. 와요는 LIVE 영상 + GPS를 보유하지만 워커 행동 이상을 탐지한다는 공개 정보가 없다.

PT는 V1.0 출시 시점부터:
- 산책 사진-캡션 pair
- GPS 궤적 + 이상 탐지 이벤트
- 사고 신고 텍스트 + severity 분류 결과
를 구조화된 형태로 적재한다. 이 데이터는 V1.1 자연어 매칭 추천 엔진의 학습 재료가 된다. **PT는 운영할수록 추천 품질이 개선되는 flywheel을 출시 첫날부터 설계에 심어둔다.**

**Layer C — 철학·포지셔닝 차별화 (Philosophy & Positioning)**

"PT는 산책 중개 플랫폼이 아니라, 보호자-펫시터 신뢰 인프라다."

도그메이트가 인수 후 오프라인 시설 하이브리드 모델로 무거워지는 방향을 선택한 시점에, PT는 의도적으로 오프라인 시설 없이 매칭-추적-사고신고-보험 자동화 4축의 "신뢰 스택"만 제공하는 lean 구조를 유지한다. 한국 시장에서 "플랫폼 신뢰"는 한 번 사고가 나면 카카오톡 채널 전파 속도가 빠르기 때문에 선제 인프라 구축이 후발 경쟁자에게는 따라오기 어려운 포지션이 된다.

**한 문장 thesis**: "PT는 5개 경쟁사가 아직 설계하지 않은 '안전 인프라 플랫폼'이다."

### 1-2. 차별화 Hierarchy — 카피 가능성 분류

| 분류 | PT 차별화 요소 | 카피 비용 + 이유 |
|---|---|---|
| 즉시 카피 (0~6개월) | GPS 실시간 추적 (와요 기존 보유), 신원조회 서류, 사진 업로드 | 서버 + API 계약. 와요 이미 보유 |
| 6~12개월 카피 가능 | AI 산책 캡션 + 리포트, 후기 모더레이션, LLM 사고 분류 | LLM API 연동 자체는 쉽지만 UX 통합 + 데이터 파이프라인 재설계 필요. 도그메이트는 인수 후 통합 운영 집중 |
| 18개월+ 또는 카피 불가 | (1) **산책·사고·매칭 통합 데이터 자산** (V1.1 추천 엔진 학습 재료), (2) **동물보호법 사고 신고 자동화 법적 정합 설계**, (3) **보험사 가맹 + 사고 기록 연동 에코시스템** | 데이터는 운영 시간이 자원. 법적 정합은 변호사 자문 + 코드 구조 재설계. 보험사 가맹은 실적 데이터 없이는 협상 테이블 자체가 안 열림 |

**평가위원 한 줄 답변**: "출시 후 누적되는 한국 산책·사고 데이터 자산과, 그 데이터 위에 동작하는 추천·보험 연동 에코시스템입니다. 데이터는 시간이 자원이어서 경쟁자가 오늘 카피를 시작해도 PT가 6개월 이상 앞서 있습니다."

### 1-3. 5축 카피 vs PT 통합 — 단일 축 카피 무력화

도그메이트가 사고 신고 버튼 하나를 카피한다고 가정. 사고 신고 기능 작동에는 해당 산책 세션의 GPS 궤적·펫시터 인증 상태·보험 가맹 정보·보호자 비상연락처가 하나의 데이터 파이프라인으로 연결되어야 한다. 버튼 하나가 아닌 **전체 세션 데이터 모델 재설계**가 필요.

와요가 GPS 이상 탐지를 카피한다고 가정. 탐지 임계값 튜닝에는 반려견 크기·체력·산책 시간대별 기준 데이터가 필요. PT는 V1.0부터 이 데이터를 수집하는 구조이고, 와요는 LIVE 영상 인프라를 운영하는 과정에서 이 데이터를 별도로 적재하지 않는다.

**단일 축 카피는 가능하지만, PT의 5축은 상호 보완적으로 하나의 데이터 파이프라인 위에 동작하기 때문에 단일 축 카피는 "형태만 있고 데이터가 없는" 기능이 된다.**

## 영역 2: 카피 방어 plan (Moat / Defensibility)

### 2-1. PT Moat 5종 분석

각 Moat의 현재 강도(1~5점) + 6/12/18개월 후 강도 변화.

**Moat 1 — 네트워크 효과 (Network Effect)**

현재 1/5. 양면 매칭 플랫폼은 보호자·펫시터 양쪽 임계질량 도달이 필요. V1.0 시점은 거의 0. 단, 산책은 지역 단위 수요이므로 Beachhead(서울 마포·용산 등 1~2 지역) 임계질량 발화 가능.
- 6개월: 2점 (Beachhead 2~3 지역)
- 12개월: 3점 (서울 주요 구 단위)
- 18개월: 4점 (플랫폼 전환 비용 발생)

**Moat 2 — 데이터 Moat (Data Moat)**

현재 1/5. 출시 전. V1.0 출시부터 수집 파이프라인 작동이 차별점. 도그메이트 15만 건 기록은 AI 추론 재료로 구조화 안 됨.
- 6개월: 2점 (산책 500~1,000건, 사고 신고 패턴 초기)
- 12개월: 3점 (자연어 매칭 V1.1 실운영 + feedback loop)
- 18개월: 4점 (보험 가맹 실적 + 이상 탐지 자동 튜닝)

**Moat 3 — 전환 비용 (Switching Cost)**

현재 1/5. V1.1 이후 보호자의 반려견 산책 기록·즐겨찾기·사고 히스토리 누적 시 상승. "내 강아지 데이터" 이전은 기술적·심리적 저항.
- 6개월: 2점 / 12개월: 3점 / 18개월: 4점

**Moat 4 — 브랜드·신뢰 Moat (Trust Moat)** — **PT의 핵심 Moat**

현재 1/5. 신뢰 플랫폼에서 사고 1건의 파급력은 비대칭. 한국 반려동물 커뮤니티(카카오톡·네이버·인스타) 촘촘한 연결로 사고 → 소셜 확산 빠름. 반대로 신뢰 쌓는 속도도 빠름. PT가 사고 신고 의무 자동화로 "사고가 나도 투명하게 처리되는 플랫폼" 포지션 선점 시 신뢰 브랜드.

**가정 (AS-T1)**: 사고 발생 시 PT가 48시간 내 처리 결과를 보호자와 공유하는 프로세스가 동작 → 투명성 자체가 경쟁자가 단기 따라오기 어려운 자산.
- 6개월: 2점
- 12개월: 3~4점 (사고 처리 사례 10건+ 축적)
- 18개월: **4~5점**

**Moat 5 — 규제·법적 Moat**

현재 1/5. 동물보호법 제8조·제46조 정합 + 위치기반서비스 신고 + PIPA 동의 체계 선제 구축이 PT 국내 first-mover 포지션.

**가정 (AS-R1, 변호사 자문 필요)**: 동물보호법 제46조 위반 과태료 사례가 산책 플랫폼에 적용될 경우, 사고 신고 자동화 미보유 플랫폼은 법적 리스크. 시나리오 현실화 시 PT 규제 Moat 즉시 4~5점.
- 6개월: 2점 (법적 구조 완성)
- 12개월: 3점 (보험 가맹 = 규제 정합 실증)
- 18개월: 4점

### 2-2. 카피 시나리오 4건 + PT 대응

**S1 — 도그메이트(메이저, 자본 풍부)가 5축 모두 카피**

도그메이트는 커넥팅더닷츠 인수 후 오프라인 하이브리드 전환에 경영 자원 집중. AI 5축 동시 카피는 별도 AI 팀 채용 + 데이터 파이프라인 재설계 + 기존 앱 UX 재설계 필요. **추정 12~18개월**. 그 사이 PT는 6~18개월치 운영 데이터 축적. 도그메이트 카피 완성 시점에 PT는 V1.1 추천 엔진이 실 데이터로 튜닝된 상태. **도그메이트 비용**: 개발 인력 3~5명 × 12개월 인건비 + 재설계 비용 + 사용자 혼란 이탈 리스크 = 추정 **2~5억 원 + 12~18개월**.

**S2 — 신규 스타트업이 PT 코드베이스 따라잡기**

PT 핵심 차별화는 코드가 아닌 데이터 파이프라인 + 운영 노하우. 신규 스타트업이 동일 기술 스택으로 앱 구축 = 6~9개월. 그러나 보험사 가맹 협상·사고 신고 법적 정합·Beachhead 펫시터 네트워크는 운영 자산. PT 대응: Beachhead 2~3 지역 공급자 밀도 빠른 선점.

**S3 — Rover·Wag·Traini 글로벌 사업자 한국 진입**

Wag 2025-07 파산 후 구조조정 → 한국 진출 여력 낮음. Rover는 한국어·보험·결제 현지화 6~12개월 소요. Traini는 wearable 기반 진입 방식 차이 → 직접 경쟁보다 협력 기회. 글로벌 진입 리스크 실재하지만 1~2년 시간 있음. PT 대응: 1년 내 한국 데이터 자산 충분히 축적 → 글로벌 진입 시 "로컬 데이터 파트너십" 또는 "인수 대상" 포지션.

**S4 — 카카오·네이버 빅테크 진입**

빅테크 강점: 트래픽·결제. 약점: 민감한 사고 처리·법적 책임·펫시터 공급자 온보딩 운영. 카카오 "카카오펫시터" 론칭 시 초기 트래픽 확보 가능하지만 사고 처리 프로세스는 트래픽으로 해결 불가. PT 대응: 빅테크 진입 전에 "사고 처리 표준" 먼저 정의. 빅테크 진입 후에는 **B2B SaaS(V2.0)로 포지션 전환** — 빅테크 플랫폼에 PT의 사고 신고 + 보험 연동 API 제공 공급자.

### 2-3. Defensibility Build Plan (12~18개월)

**1~3개월 (V1.0 출시 직후, 2026-06~08)**

- PT 카피 비용: 동일 지역 펫시터 50명 확보 = **2,000~5,000만 원 + 2~3개월**

```
단위경제가 성립하는가. 기본 시나리오: ARPU 6,600원/월 × LTV 14개월 =
92,400원. CAC 15,000원. LTV/CAC = 6.16. 이 수치는 초기 CAC를 커뮤니티
바이럴(반려동물 카페·인스타그램 콜라보)로 낮게 유지하는 것이 전제이며,
유료 광고 의존도가 높아지면 CAC가 30,000원 이상으로 올라 LTV/CAC 3.1로
하락할 수 있다. 따라서 초기 18개월 마케팅 전략은 커뮤니티 중심 유기적
성장에 집중한다.

V1.1에서 R2(펫시터 구독)·R4(보호자 구독)가 추가되면 ARPU가 20~30% 상승.
V2.0 B2B SaaS는 LTV가 1,000만 원 단위(기관 × 12개월 계약)로 올라가므로
이 시점이 Series A의 자연스러운 사용처. 출시 3개월(2026.10) 실측 ARPU와
이탈률 데이터를 Series A deck에 첨부할 수 있는 상태로 준비한다.
```

**페르소나별 가산 효과 (영역 3)**: P1 +3~5 / P2 **+3~5** / P3 +1~2 / P4 **+2~3** / P5 +2~3

## 면접 답변 가이드

**Q1 — "기존 앱과 뭐가 다른가?"**

> "첫째, 사고 신고가 자동으로 처리됩니다. 5개 경쟁사 모두 펫시터가 수동으로 보호자에게 연락하는 구조입니다. PT는 사고 버튼 하나로 119 알림·보호자 SMS·동물병원 GPS 안내·증거 기록이 자동으로 처리됩니다. 둘째, 운영할수록 추천 품질이 개선되는 구조입니다. 매 산책마다 AI 캡션·GPS 궤적·사고 기록이 쌓이고, 이것이 V1.1 추천 엔진의 학습 재료가 됩니다. 경쟁사는 같은 기능을 붙여도 이 데이터 없이는 추천 품질에서 뒤처집니다."

**Q2 — "경쟁사가 카피하면?"**

> "기능을 카피하는 데 6~12개월, 데이터 자산을 따라잡는 데 12~18개월이 걸립니다. 도그메이트는 현재 인수 후 오프라인 하이브리드 전환에 집중하고 있어 AI 우선순위가 낮습니다. 와요는 LIVE 영상 운영 비용이 높아 AI 추가 투자 여력이 제한됩니다. PT가 출시 후 6개월 안에 Beachhead 지역 펫시터 네트워크와 보험사 가맹을 선점하면, 이것은 데이터가 아닌 운영 자산으로 카피 불가능합니다."

**Q3 — "BM이 구체적으로 뭔가?"**

> "핵심은 거래 수수료 15%입니다. 산책 1건 22,000원이 이루어지면 3,300원이 PT 수익입니다. 변동비(결제 수수료·LLM API) 약 1,200원 빼면 건당 공헌이익 2,100원. 월 고정비 50만 원을 내려면 월 238건이면 됩니다. 펫시터 100명이 월 2.5건씩 매칭하면 달성 가능합니다. 출시 후 6~9개월 목표이며, V1.1에서 펫시터 구독료와 보험 가맹 수수료가 추가됩니다."

**Q4 — "1억 원으로 뭘 하는가?"**

> "코드는 이미 완성했습니다. 1억 원의 100%는 출시 후 성장 가속에 씁니다. 마케팅 2,500만 원으로 보호자 300명·펫시터 100명을 Beachhead 지역에서 확보하고, 법무·보험 가맹 협상에 800만 원, 인프라 12개월 운용에 2,000만 원을 씁니다. 이 집행 계획이 통합관리지침의 항목별 한도(외주 50%, 인건비 40%) 이내임을 확인했습니다."
