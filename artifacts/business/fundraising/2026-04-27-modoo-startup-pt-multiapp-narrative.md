## 5. "1개 자금으로 3개 앱 launch" 주장의 합리성

### 5.1 핵심 전제 (모두 충족 필요)

| 전제 | 현재 상태 | 위험도 |
|---|---|---|
| PT 인프라가 CC/SafeWay 기반으로 재사용 가능 | 백엔드 87% 재사용률 확인 | 낮음 |
| 1인 창업자가 앱별 순차 개발 가능 (병렬 X) | PT 우선, CC 90일 후, SafeWay 별도 | 중간 (운영 부하) |
| 인프라 비용이 marginal cost 구조 | 증분 월 3,000~5,000원 확인 | 낮음 |

### 5.2 "1개 자금"의 의미 (오해 방지)

⚠️ "1개 자금으로 3개 앱을 동시에 런칭"이 아니라 **"PT 자금 → PT 출시 → PT 수익으로 CC 개발비 충당 → CC 출시"의 순차 레버리지 구조**.

```
[모두의 창업 1억원 자금]
        │
        ▼
[6/4 PT V1.0 launch (무결제)]
        │
        ├─→ 7월 사업자등록 + PortOne v2 활성화
        │       │
        │       ▼
        │   [7월~ PT 매출 발생, MRR 220K~750K (Realistic~Aggressive)]
        │       │
        │       ▼
        │   [PT 매출 ─→ CC 개발 추가 자원]
        │
        ▼
[PT 출시 +90일: 2026-09 ~ CC launch 준비]
        │
        ▼
[CC launch (PT 백엔드 87% 재사용, 모바일 50% 재사용)]
        │
        ▼
[CC 매출 발생 → PT + CC 멀티앱 운영 단계]
        │
        ▼
[SafeWay Kids 샌드박스 승인 시 → 별도 launch (이미 코드 완성)]
```

### 5.3 평가위원 반박 차단 narrative

> "단일 자금으로 3개 앱 launch는 동시 개발이 아닌 **순차 레버리지 구조**입니다. 모두의 창업 자금은 PT V1.0 launch 가속과 결제 인프라 활성화에 100% 집중되며, CC와 SafeWay는 PT의 백엔드 87% 재사용 + 모바일 50% 재사용 + 인프라 marginal cost +3,000~5,000원/월 구조로 PT 매출 발생 후 단계적으로 launch됩니다. 이는 '1인이 동시에 3개 앱 운영하는 게 가능하냐'는 우려를 차단하는 시간축 분리 전략입니다."

## 7. 평가위원 회계 페르소나 답변 (7 질문)

신청서 면접 단계 사전 준비.

### Q1. "수익 모델 검증된 데이터는?"
**A (50자)**: "한국 경쟁사(도그메이트, 와요) 수수료 20% 대비 15% 설계, Rover 20% 수수료 $2.3B 인수 사례 벤치마크."
**보강**: 실 결제 데이터는 무결제 출시(7월 이후) 결정으로 현재 없음. 도그메이트·와요·케어독 공개 가격표 기반 AOV 25,000원, Rover 모델 검증, Wag! 40% 실패 반면교사 15% 설정. 출시 후 3개월(2026-10) 검증 마일스톤.

### Q2. "1인 창업가가 멀티앱 운영 가능 근거?"
**A (50자)**: "50K LOC 4개월 구현 완료, AI 보조 개발로 3인 팀 동등 생산성, 앱 순차 출시(PT→CC 90일)."
**보강**: 동시가 아닌 순차 레버리지. PT 출시 후 CC는 백엔드 87% + 모바일 50% 재사용으로 추가 개발만 필요. AI 보조 개발 도구 없이는 불가능, Claude Code 기반 4개월 50K LOC + 210+ 테스트 실적 증거. SafeWay는 코드 완성 + 샌드박스 병렬 진행. SDET Code 운영 부하 최소.

### Q3. "PG 미연동 + 사업자 미등록 상태에서 매출 가정 신뢰도?"
**A (50자)**: "7월 유료 전환 목표, 그 전 MRR=0. 6/4~7월 PMF 검증 기간으로 매출 주장 없음."
**보강**: 6/4~7월 사이 매출 주장 없음. 6/4는 무결제 PMF 검증 단계, 7월 사업자등록 + PortOne v2 후 유료 활성화. 신청서 timeline에 "6/4~6월 MRR 0원, 사전 가입자 트랙션 검증 / 7월 유료 활성화 MRR 첫 발생 / 8~9월 정상화" 솔직 기재.

### Q4. "락인 인센티브 누적 비용?"
**A (50자)**: "Realistic 60명 전환 시 총 292,500원. 1인당 평균 4,875원, LTV 45,375원 대비 10.7%."
**보강**: 권장 조합(1개월 무료 + 3개월 10% 할인) 기준. 총 비용 292,500원 = 서버 운영비 한 달 치 3~4배. 평가위원 앞에서는 "1개월 무료만" 단일 옵션(1인당 3,750원, CAC 18,750원, LTV:CAC 2.73배) 제시 더 방어 용이.

### Q5. "사전 가입자 100명 5/15까지 모은다는 가정 근거?"
**A (50자)**: "네이버 반려동물 카페(10만+ 회원) 2개소 홍보 + 랜딩 CVR 8% + 오프라인 파트너십 1~2곳."
**보강**: 100명은 Realistic(95명)과 Aggressive(306명) 사이. 강사모·반려동물 사랑 등 10만+ 카페 정보성 게시물 1개당 15~50명 가입 현실적. 2개 카페 + 랜딩 + 지인으로 95~100명 보수 달성. ±50% 변동 가능 명시.

### Q6. "PortOne 가맹점 계약 7월 안에 100% 체결?"
**A (50자)**: "보증 없음. PortOne 계약 영업일 5~10일, 사업자등록 후 즉시 신청, plan B = 토스페이먼츠."
**보강**: 보증보다 솔직한 리스크 표현이 신뢰도 높음. PortOne v2 통상 5~10영업일. 7월 사업자등록 직후 신청 → 7월 내 활성화 현실적. Plan B로 토스페이먼츠 단독 (provider 추상화 완료, 코드 변경 없이 전환).

### Q7. "예비창업자 자격이 7월 직전 문제 시 plan B?"
**A (50자)**: "사전 가입자·코드 자산은 법인 이전 가능. TIPS 트랙 또는 초기창업패키지 전환."
**보강**: 시나리오 A — 협약 전 사업자등록 강제: 자격 포기 → 루넨랩스 법인 → PT 자체 수익. 시나리오 B — 자격 해석 문제: 5/7 이의림 변호사 사전 확인. 평가위원에게는 "TIPS 연계 또는 초기창업패키지 전환"이 더 긍정적 (TIPS는 예비창업자 제약 없음).
