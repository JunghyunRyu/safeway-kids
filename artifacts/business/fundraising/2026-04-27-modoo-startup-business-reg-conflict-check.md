## Q1. 사업자등록 없이 PortOne v2 가맹점 계약 가능한가?

**차단 여부: 🔴 차단**

### 근거

PortOne(구 아임포트) 가맹점 계약 = 전자금융거래법 §28·§30, 여신전문금융업법 §19 체계 안에서 동작.

- 가맹점 계약 시 사업자등록증 또는 법인등기부등본 = 필수 첨부 서류
- 개인사업자(미등록 자연인) 명의의 PortOne v2 본 계약은 PortOne 표준 약관상 불허 (추정 — 공식 약관 직접 확인 필요)
- 테스트 모드 + 개발 계정은 개인 이메일로 발급 가능 / 실 결제 프로덕션 전환 = 가맹점 계약 선행

### 대안 PG 비교 (추정)

| PG사 | 사업자 미등록 계약 | 비고 |
|---|---|---|
| PortOne v2 (NHN KCP/KG 이니시스 등) | 🔴 불가 | 가맹점 계약 = 사업자 필수 |

## Q2. 사업자등록 없이 PT V1.0 앱스토어/Google Play 출시 가능한가?

**차단 여부: 🟡 부분 차단 (등록 자체는 가능, 유료 기능만 차단)**

### 근거

**Apple App Store — Individual 계정**:
- 자연인 개인 명의 등록 가능, 한국 사업자등록증 미요구
- IAP 자체는 사업자 여부와 무관, Apple Developer Program 약관만 준수
- 단, 한국 전자상거래법 §12 통신판매업 신고 의무 = 사업자 선행 필요

**Google Play Console — Individual 계정**:
- 개인 개발자 계정 등록 가능, 한국 사업자등록증 미요구
- Organization 전환 = 차후 가능 (단 Personal → Organization 직접 전환 X, 새 계정 + 앱 이전 방식 / 추정)

**한국 전자상거래법 §12 (통신판매업 신고)**:
- 유료 거래 시 신고 필수, 신고 요건 = 사업자
- 미신고 유료 거래 = §45 과태료 처분 대상
- 플랫폼(Apple/Google)이 차단하지는 않음 / 한국 공정위 제재 가능

**Organization 전환**:
- Apple: Individual → Organization 가능, 계정 업그레이드 (앱 데이터 유지)
- Google: Personal → Organization 직접 전환 X, 새 계정 + 앱 이전 (리뷰·다운로드 히스토리 손실 리스크 / 추정 — 공식 Help Center 직접 확인 필요)

### 우회 경로

| 경로 | 가능 | 리스크 |
|---|---|---|
| Individual 계정으로 무결제 앱 등록 | ✅ 가능 | 통신판매업 신고 의무 없음 |
| 사업자등록 후 Organization 전환 | Apple ✅ / Google 🟡 | Google 히스토리 손실 가능성 |
| 무결제 6/4 출시 → 7월 결제 활성화 | ✅ 가능 (사용자 채택) | 수익 1개월 지연 |

### 확인 필요
- Google Play: Personal → Organization 전환 시 리뷰·히스토리 유지 여부 (공식 Help Center)
- 통신판매업 신고 의무: 무결제 운영이 거래에 해당하지 않는지 (전자상거래법 해석)

## Q3. 사업자등록 없이 SafeWay 규제 샌드박스 5/7 미팅 자격이 유지되는가?

**차단 여부: 🟡 부분 차단 (5/7 미팅 자체 가능, 신청서 표기 불일치 리스크)**

### 근거

**정통융합법 §36 (실증특례 신청)**:
- "정보통신융합 등 기술·서비스를 개발하거나 사업화하려는 자"
- 사업자·사업자등록증 보유자 한정 문구 없음
- 과기정통부 가이드라인 (추정): 법인·개인사업자·예비창업자 모두 신청 가능 (최신본 직접 확인 필수)

**5/7 미팅 성격**:
- 정식 심사 청문 X / 사전 상담·신청서 보강 검토 성격
- 사업자등록증 없어도 미팅 진행 가능
- 변호사가 "사업자등록 현황" 질문 가능성 높음 → 신청서 표기와 실제 일치 필수

**핵심 충돌 — 신청서 v2.0.4 §0 표기 불일치**:
- 현 표기: "㈜루넨랩스 (법인 설립 절차 진행 중, 2026년 2분기 내 완료 예정)"
- 실제 결정: 사업자등록 7월까지 보류
- 행정기본법 §18 ③: 거짓·부정 처분 취소 가능 → **표기 수정 필수**

### 5/7 미팅 전 행동

1. 신청서 §0 표기 수정 (옵션 A/B/C는 KRC 자문 결과로 결정)
   - 옵션 A: "예비창업자 류정현" 명의 변경
   - 옵션 B: "루넨랩스 (사업자등록 2026-07월 예정, 모두의 창업 프로젝트 2026 협약 후 진행)" 솔직 표기
   - 옵션 C: 현 표기 유지 + 이의림 변호사 합의 후 사후 수정
2. ICT 규제샌드박스 운영기관(NIPA·과기정통부)에 예비창업자 신청 허용 직접 확인
3. 5/7 미팅 1차 안건 = 본 충돌 점검 결과 + 변호사 의견 청취

### 정면 충돌 시나리오

심사위원회가 실증특례 승인 조건으로 법인 설립·사업자등록 완료를 부과하면:
- 모두의 창업 자격(예비창업자) vs 샌드박스 조건(사업자) 정면 충돌
- 사용자 결정 필요: 둘 중 하나 포기
- 단, 샌드박스 최종 승인 시점(통상 신청 후 60~90일) > 모두의 창업 협약(7월)이면 충돌 자동 해소 가능

### 확인 필요
- 과기정통부 ICT 규제샌드박스 가이드라인 최신본 (예비창업자 신청 허용)
- 실증특례 승인 시 법인화 조건 부과 가능성 (심사위 재량)
- 이의림 변호사 5/7 미팅 사전 이메일 (KRC가 초안 작성 중)
