## 3. PT 차별화 3축 (white space 명시)

> 신청서 §혁신성에 raw input. 평가위원 P3(산업 전문가)가 인정 가능한 **미발굴 white space**.

### 축 1: 사고 신고 의무 자동화 (법적 의무 연계)

**시장 현황**: 5개 경쟁사 모두 사고 발생 시 펫시터 → 보호자 수동 알림에 의존. 119 호출·동물 응급의료 연결은 보호자 책임. 동물보호법 제8조(동물학대 금지), 제46조(과태료) 위반 시 펫시터·플랫폼 책임 분리 모호.

**PT 솔루션**:
- 산책 중 사고 신고 버튼 → **자동 119 알림 + 보호자 SMS + 가까운 동물병원 GPS 안내**
- 사고 기록 자동 저장 → 법적 분쟁 시 증거
- 동물보호법·교통사고처리특례법·보험사 약관 통합 매핑 (V1.1)

**평가위원 narrative**: "PT는 5개 경쟁사 중 유일하게 사고 신고를 법적 의무 차원에서 자동화한다. 이는 보호자 신뢰 격차를 메우면서 동시에 펫시터 책임 보호 — 양쪽 stakeholder 동시 가치."

### 축 2: 보호자 부재 시 트래픽 데이터 기반 추천 (V1.1)

**시장 현황**: 5개 경쟁사 모두 **펫시터 추천이 정적** (거리·평점·가격). 보호자 일정·반려견 컨디션·과거 산책 기록을 통합 추천하지 않음.

**PT 솔루션** (V1.1):
- 반려견 산책 기록 (시간·거리·강도) 자동 학습
- 보호자 일정 (캘린더 연동) → 부재 시 사전 추천
- 트래픽 + 날씨 + 펫시터 가용성 통합 알고리즘
- "오늘 못 가실 것 같은데, 이 시간대 가능한 펫시터 3명 있어요"

**평가위원 narrative**: "기술 중심 1인 창업가의 차별화는 데이터·알고리즘. PT는 출시 후 누적 데이터를 V1.1 추천 엔진으로 자동 강화하는 구조."

### 축 3: 의도적 lean 모델 (도그메이트 인수 후 하이브리드 대비)

**시장 현황**: 도그메이트는 인수 후 **방문 펫시터 + 자체 오프라인 시설 (업계 최초 하이브리드)** 모델로 확장. 이는 운영 복잡도 증가 + CAPEX 부담.

**PT 솔루션**:
- **오프라인 시설 의도적 미보유** — 매칭 플랫폼만 운영
- 운영 비용 = 서버 + AI API + 보험 가맹 수수료 (월 ~50만원 추정)
- **1인 창업가 + 자동화 + 외주 펫시터** = 도그메이트 대비 30~50배 lean
- 단, V2.0에서 B2B SaaS (강아지 학교·동물 병원) 확장 시 추가 segment

**평가위원 narrative**: "도그메이트가 인수 후 하이브리드 모델로 무거워지는 시장 환경에서, PT는 lean 매칭 플랫폼으로 1인 창업가 모델의 강점을 유지한다. 사용자 1인 손익분기점(BEP)이 도그메이트 대비 1/30."
