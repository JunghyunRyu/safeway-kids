**작성 목적**: K-Startup 원스톱 심화상담(법률(국내) · 규제·인허가 대응) Build 3 첨부자료

**신청 주체**: SafeWay Kids 팀 (법인 설립 준비 중, 기술창업 예비창업자)

## 1. 서비스·법적 구조 개요

SafeWay Kids는 학원·유치원 등 어린이 교육시설(A)과 여객자동차운수사업법상 전세버스 면허를 보유한 전세버스운송사업자(B)를 **N:N**으로 중개하는 플랫폼입니다.

- **차량 소유**: 전세버스사업자(B) — 플랫폼 미소유
- **운전자 고용**: 전세버스사업자(B) — 플랫폼 미고용
- **법적 포지션**: 여객자동차법 §49조의2 제3호 "여객자동차운수사업자 운송중개업"
- **부가 기능**: 동적 배차, 엣지 AI 안전 모니터링, 학부모-기사 양방향 메시징, 빌링

### 선례
- ㈜스쿨버스 RIDE 플랫폼 — ICT 규제샌드박스 동일 카테고리 통과 (safeschoolbus.net)

## 2. 대법원 판례 2008두21294와 본 사업 계약 구조

### 2.1 판례 개요 (인용 확인 필요)

- 판시 방향: 전세버스사업자가 정해진 노선에 따라 지속적으로 승객을 태우고 대가를 받는 경우 "노선여객자동차운송사업"으로 간주
- 판례 핵심 기준: (a) 운행계통 고정 여부, (b) 운송 대상의 특정·단일성

### 2.2 본 사업 계약 관계도

```
[교육시설 A] ──── 운송계약 A ──┐
                               │
                               ├─> [전세버스사업자 X]
                               │        │
[교육시설 B] ──── 운송계약 B ──┘        │
                                         │
[플랫폼 SafeWay Kids] ─ 중개·배차 ──────┘
                                         │
                                         ▼
                                    [동일 차량]
                               (유휴 시간대 분할 이용)
```

**특징**
- 각 교육시설은 전세버스사업자와 **별개** 계약 체결
- 플랫폼은 두 계약을 매칭하지만 자체 운송계약 체결 없음
- 동적 배차(DRT)로 매일 경로 재계산 → "정해진 노선" 반복성 회피 설계

### 2.3 법적 쟁점

판례의 "1개 운송계약" 기준이 "사업자-단체 간 단일 계약"만을 전제하는지, 아니면 "복수 독립 계약의 병렬"도 포섭하는지 공개 해석 부재. 후자 해석이면 본 사업 구조가 판례 불리 방향으로 재분류될 위험.

## 3. AI 기본법 §33 이행 체계 (2026-01 시행)

### 3.1 조문 구분

| 조항 | 성격 | 내용 |
|---|---|---|
| §33 ① | **의무** | 고영향 AI 사업자는 사전 내부 검토를 **하여야 한다** |
| §33 ② | **권리** | 고영향 AI 사업자는 과기정통부 장관에게 확인을 **요청할 수 있다** |

### 3.2 당사 §33 ① 이행 구조 초안

| 구성 요소 | 계획 | 상태 |
|---|---|---|
| 사내 AI 위원회 결정문 | 분기 개최, 위원 외부 포함 | 구조 설계 중 |
| PIA(개인정보영향평가) 보고서 | 엣지 AI 추론 파이프라인 대상 | 초안 작성 중 |
| 기술 리스크 평가서 | VRP-TW·안면 임베딩·양방향 메시징 각 모듈별 | 초안 작성 중 |
| 위험관리 매뉴얼 | 실증 개시 전 확정 + 분기 갱신 | 설계 중 |
| 이의제기 창구 | 이용약관 명시 | 구조 설계 중 |

### 3.3 §33 ② 장관 확인 요청 신청 시점 불확실성

- 옵션 A: 실증특례 신청과 **동시 제출** (과기정통부 단일 창구)
- 옵션 B: 실증 개시 전 **별도 절차**
- 옵션 C: 실증 승인 후 **운영 중 임의 시점**

시행령 확정 전이라 공식 가이드 부재. "부(否)" 결정 시 실증 신청에 미치는 영향도 미확인.

## 4. 정보통신망법 §44의2 — 학부모-기사 메시징 구조

### 4.1 메시징 설계

- **대상**: 학부모(보호자) ↔ 전세버스 기사
- **용도**: 등·하원 시각 조정, 긴급 연락, 탑승 확인
- **구조**: 애플리케이션 내부 채널 (플랫폼 서버 경유)
- **보관**: 메시지 본문 6개월 보관 후 자동 파기
- **공개 범위**: 양자 간 사적 채널, 제3자 조회 불가

### 4.2 §44의2 적용 여부 쟁점

- "정보통신망을 통하여 일반에게 공개된 정보" 정의에 학부모-기사 사적 채널이 해당하는가
- 양자 간 사적 통신이면 §44의2 적용 제외 (임시조치 의무 없음)
- 일반 공개에 해당하면 임시조치 의무(게시 삭제·차단)가 발생

### 4.3 1인 창업가 24~48시간 이행 가능성

임시조치 의무 발생 시 요구되는 대응:
- 신고 접수 → 검토 → 게시물 접근 제한 또는 삭제 → 게시자 소명 기회 부여
- 24~48시간 내 1인 창업가가 이행 가능한 자동화·수동 혼합 구조 필요
- §44의3 명예훼손 분쟁조정 절차도 중복 발생 가능

### 4.4 6개월 보관과 증거 보존 의무 충돌 가능성

본 설계의 6개월 자동 파기가 §44의2 분쟁 발생 시 증거 보존 요건과 충돌하는지, 또는 보관 기간을 선택적으로 연장해야 하는지 확인 필요.
