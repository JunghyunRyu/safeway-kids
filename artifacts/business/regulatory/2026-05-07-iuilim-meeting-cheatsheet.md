## §2. 꼭 말하지 말아야 할 것 (must-NOT-say)

### A. 사업 모델 misframe — 절대 금기어

| 금지 | 안전 대체 |
|---|---|
| "우리 차량" / "직접 소유" / "직접 운영" / "직접 운송" | "전세버스사업자가 소유한 차량" |
| "기사 고용" / "기사 채용" | "사업자 소속 운수종사자" |
| "학원끼리 차량 공유" / "유휴 차량 빌려준다" | "동일 사업자가 학원 A·B와 별개 운송계약" |
| "노선 운행" / "정해진 노선" | "DRT 동적 배차 / 시간창 기반 매칭" |
| "한정된다" | "5개 핵심 기능으로 분류" |
| "타다·쿠팡플렉스·배민라이더스·카카오T 블루" 비유 | RIDE(스쿨버스)만 비유 |
| "㈜루넨랩스" / "루넨랩스" / "류재훈" | "신청사 (사업자 등록 단계)" / "류정현" |

### B. 자기 anchor 약화 발언

| 금지 발언 | 잃는 anchor |
|---|---|
| "사실 §49의2 제3호 등록만으로 가능할 수도 있다" | 신청 명분 자기 부정 — v2.1 §2.1 답변 무너짐 |
| "고영향 AI일 수도 있다고 생각한다" | 양길모 Q2 anchor 약화 — §2.7·§4.6 이중 트랙 frame 붕괴 |
| "§44의2 보관 의무가 있을 수도 있다" | 헌재 2016헌마275 anchor 약화 — §4.7 신설 의미 상실 |
| "양길모 의견서가 약하다고 생각한다" | cross-check가 second opinion으로 변질 |

### C. 즉석 약속·확약

- ❌ "변호사님 의견대로 v2.2에 반영하겠습니다" → ✅ "검토 후 반영 방향 정하겠습니다"
- ❌ "운영기관에 변호사님 성함을 anchor로 인용하겠습니다" → 인용 동의 별도 절차 필요
- ❌ "변호사님이 직접 운영기관에 의견서 제출해주실 수 있나요?" → 권한 외 요청
- ❌ "법인 설립 후 정식 자문 계약하고 싶습니다" → 무료 서비스에 영업 부담

### D. 불필요한 자기 정보 노출

- ❌ 매출·운영자금 수치  ❌ 다른 사업체(SDET Code/PetTracker/CareConnect) 언급  ❌ 양길모 자문료(100만원)
