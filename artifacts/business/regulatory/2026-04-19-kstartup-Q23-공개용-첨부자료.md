## 1. 서비스·법적 구조 개요

SafeWay Kids는 학원·유치원 등 어린이 교육시설(A)과 여객자동차운수사업법상 전세버스 면허를 보유한 전세버스운송사업자(B)를 **N:N**으로 중개하는 플랫폼입니다.

- **차량 소유**: 전세버스사업자(B) — 플랫폼 미소유
- **운전자 고용**: 전세버스사업자(B) — 플랫폼 미고용
- **법적 포지션 후보**: 여객자동차법 §49조의2 제3호 "여객자동차운수사업자 운송중개업"
- **1인 운영 제약**: 엣지 AI 하드웨어 · CCTV · 스마트 미러 설치·AS를 1인이 감당 불가 → SW-only Plan B 검토

## 2. SW-only Plan B 범위 정의

### 2.1 포함 기능

- 모바일 앱 (학부모·기사·운영자용)
- 웹 대시보드 (플랫폼 관리자·학원 관리자)
- FCM 푸시 알림
- Kakao Map API 기반 경로·위치 조회
- WebSocket 실시간 위치 공유 (부모 동의 기반)
- 빌링 (Toss Payments)
- **기사 수동 탑승 확인** (앱 체크인 — AI 감지 없음)
- 학부모-기사 양방향 메시징 (앱 내부)

### 2.2 제외 기능

- NVIDIA Jetson 엣지 AI 추론
- 차량 내 CCTV 촬영
- 안면 임베딩 벡터 생성·매칭
- 스마트 미러 표시 장치
- 생체인식 탑승 확인

### 2.3 대체 방식

| 기능 | 풀스택 버전 | SW-only Plan B |
|---|---|---|
| 탑승 확인 | 엣지 AI 안면 인식 | 기사 앱 체크인 수동 입력 |
| 미탑승 감지 | AI 자동 스캔 | 기사 확인 + 학부모 통지 지연 가능 |
| 이상행동 감지 | 엣지 AI 실시간 추론 | 해당 기능 제외 |
| 위치 추적 | 엣지 + GPS | GPS 단독 (부모 동의 기반) |

## 3. V1 / V2 단계적 전환 경로

### 3.1 V1 (샌드박스 승인 전, SW-only 단순 중개)

```
[교육시설 A] ─── 직접 계약 ─── [전세버스사업자 X]
[교육시설 B] ─── 직접 계약 ─── [전세버스사업자 X]
                    │
                    └─── [플랫폼] ─── 매칭 안내만 제공
                                      (동적 배차 알고리즘 비활성)
```

- **플랫폼 역할**: 계약 매칭 + GPS 조회 + 푸시 알림 + 빌링
- **동적 배차 비활성**: VRP-TW 알고리즘 미작동. 학원·사업자가 수동으로 경로·시각 결정
- **법적 포지션 후보**: 여객자동차법 §49조의2 제3호 중개업 등록만으로 합법 여부 확인 필요
- **규모**: 학원 1~3곳, 단일 전세버스사업자

### 3.2 V2 (샌드박스 승인 후, 동적 배차 활성)

```
[교육시설 A] ─┐
[교육시설 B] ─┼─── [플랫폼] ─── VRP-TW 동적 배차 ─── [전세버스사업자 X]
[교육시설 C] ─┘                                         (동일 차량 유휴 시간대 매칭)
```

- VRP-TW 동적 배차 알고리즘 활성
- N:N 유휴 차량 공동 이용
- 샌드박스 실증특례 적용 범위

### 3.3 전환 시점의 법적 쟁점

V1 → V2 전환 시 정보통신융합법상 **특례 조건 변경 승인**이 별도 필요한지, 또는 V2 전환 시점에 **새로운 실증특례 재신청**이 요구되는지 공식 해석 부재.

## 4. 파일럿 단계 배상 한도 축소 검토

SW-only Plan B는 생체정보 위반 리스크가 원천 제거되고 플랫폼 기여 책임도 축소됩니다. 파일럿 단계에서 약관상 배상 한도를 다음과 같이 축소하는 방안을 검토 중입니다.

| 항목 | 풀스택 버전 약정 | 파일럿 축소안 |
|---|---|---|
| 법정손해배상 기준 | 법정손해배상액 | 동일 |
| 자체 위로금 | 법정손해배상의 2배 자발적 보상 | 법정손해배상의 1배 (자발적 위로금 미포함) |
| 보장 범위 | 탑승·하차·이상행동 전부 | 탑승·하차만 |

**법적 리스크 쟁점**: 축소 시 (a) 표시광고법 (과장 광고 회피), (b) 약관규제법 (면책 조항 유효성), (c) 민법 §398 ② (손해배상 예정·과실상계), (d) 개인정보보호법 §39의2 (법정손해배상 병존) 각각 리스크 재발 여부.

## 6. 자문 요청 범위 요약

본 자료와 함께 별도 신청 본문에 기재된 3개 질문에 대한 전문 변호사 자문을 요청합니다.

1. **단순 중개 vs 동적 배차 법적 경계선** — V1/V2 단계적 합법 전환 경로 성립 여부

3. **파일럿 단계 약관 배상 한도 축소 가능성** — 최소 유효 수준과 법적 리스크

**본 질문의 답변은 사업 개시 타이밍 결정의 핵심 변수**이며, 답변 방향에 따라 2026년 5월 즉시 파일럿 개시 또는 샌드박스 승인 후 파일럿 개시로 분기됩니다. 구속력 있는 최종 결정은 면허 변호사 서면 의견서 수령 후에 내립니다.
