## 적용된 대체 문구 (v2.0.4)

### 약정 A → §4.4 T+0 / T+60분·T+익영업일 09시 구조
- "24시간 고객센터(사람)" 삭제 → "24시간 자동 접수(자동응답 시스템)" + 담당자 응대 시간 명시
- "T+30분 동시 통보" 삭제 → "T+60분(업무시간 내) / T+익영업일 09시(업무시간 외) 순차 통보"
- 개보법 §34 ② 72시간 법정 신고는 별도 이행 명기
- 파일럿 규모(원생 30~50명) 이행 가능 체계임을 선언 + 확장 시 인력 비례 증설 약속

### 약정 B → §4.5 §39의2 법정손해배상 + 이용약관 확정 시 사전 보고
- "업계 표준의 3배 가중" 완전 삭제
- 개보법 §39의2 법정손해배상(건당 최대 300만 원) 기본 이행
- 추가 보상 절차는 법인 설립 후 법무 자문 → 이용약관 명문화 → 과기정통부 사전 보고
- 사업자 배상책임보험 실증 개시 30일 전 가입 조건

### 약정 C → §4.6 §34 ①-4 행 재구성
- "관제센터 인간 관제사 2차 확인 + 월간 인간 감사" 삭제
- "운행 시간대 대시보드 실시간 확인 1일 1회 이상 + 월 1회 AI 오인식 전수 검토 보고서" 채택
- "상시 감독" 표현 사용 금지
- 도로교통법 §53 제3항과의 "동일 구조" 등치 표현 삭제 → "별개 조항, §4.1에서 독립 이행"
- 시행령 구체 기준 확정 시 재조정 약속 + 과기정통부 유권해석 확보 병행

## 잔존 불확실성 (변호사 Q22 신설 권고)

1. **약정의 법적 지위** — 신청서 약정이 실증특례 승인 조건으로 편입될 때 (a) 단순 의사 표명 / (b) 편무적 약정 / (c) 조건부 계약 중 무엇인가? 이행 불능 시 **취소 처분 요건과 비례 원칙** 적용 방식.
2. **AI 기본법 §34 ①-4 시행령 "사람의 관리·감독" 구체 기준** — 2026-04 현재 시행령 미확정(추정). 1인 이행이 위법인지 여부. 시행령 확정 시 소급 미이행 리스크.
3. **개보법 §39의2 법정손해배상 + 이용약관 약정 배상액 병존** — 피해자가 둘 중 선택 청구 가능한가, 중복 배제인가.
4. **"업계 표준"이 아닌 "플랫폼 자체 기준"으로 배수 약정 재작성 가능성** — 예: "법정손해배상의 2배까지 신청사가 자발적 보상"이 약관규제법·민법 §398 ② 리스크를 회피할 수 있는가.
