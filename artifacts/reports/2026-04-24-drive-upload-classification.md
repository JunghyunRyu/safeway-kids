## 차단 사유 (참고)
폴더 5개는 자동 생성됐지만, 파일 콘텐츠 base64 인코딩이 시스템 안전 정책에 의해 차단됨 — "민감 내부 문서를 외부 시스템으로 전송 (data exfiltration)" 분류. 사용자 본인 Google Drive라도 harness 관점에서는 외부 시스템.

향후 자동 업로드를 원하면 `.claude/settings.local.json`에 다음 권한 추가:
```json
{
  "permissions": {
    "allow": [
      "mcp__claude_ai_Google_Drive__create_file"
    ]
  }
}
```
단, 위 설정은 **민감 문서를 자동 업로드 가능하게 만드는 의미**이므로 보안 트레이드오프 신중히 고려.
