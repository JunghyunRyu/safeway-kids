# 한국 앱스토어/플레이스토어 출시 요건 리서치

**작성일:** 2026-04-02  
**목적:** SafeWay Kids 앱의 Apple App Store / Google Play Store 출시를 위한 사업자등록 및 법적 요건 조사

---

## 1. 사업자 등록 필요 여부

### 1.1 Apple Developer Program (개인 가입)

| 항목 | 내용 |
|------|------|
| **개인(Individual) 가입** | 사업자등록 없이 가능. 신분증(여권 등)으로 본인 인증 후 가입 |
| **연간 비용** | USD 99 (한국 원화로 결제, 약 13~14만원) |
| **가입 절차** | Apple ID → 개인정보 입력 → 본인 인증 → 결제 → 승인 |
| **법인/기업 가입** | D-U-N-S Number 필요 (나이스디앤비에서 발급, 수수료 발생) |
| **개인사업자** | Apple에서는 개인사업자를 Individual로 취급. 별도 기업 계정 불가 |
| **수수료 면제** | 한국은 Fee Waiver 대상국이지만, 개인/개인사업자는 면제 불가 |

**결론:** Apple Developer Program 자체에는 사업자등록 없이 개인으로 가입하여 앱 출시 가능.

### 1.2 Google Play Console (개인 가입)

| 항목 | 내용 |
|------|------|
| **등록비** | USD 25 (1회성) |
| **개인 계정** | 2023년 11월 13일 이후 생성된 개인 계정은 **신규 앱 등록에 심각한 제약** |
| **조직 계정** | 2024년부터 신규 앱은 **조직(Organization) 계정으로만** 프로덕션 등록 가능 |
| **개인사업자** | 조직 계정 생성 가능 (법인이 아니어도 됨) |
| **필요 서류** | 사업자등록증 + 대표자 신분증 |

**핵심 변경 (2024):**
- 신규 개인 계정 개발자는 프로덕션 출시 전에 **테스터 최소 12~20명**을 모집하여 **14일간 비공개 테스트**를 통과해야 함
- 조직 계정은 이 제한 없이 바로 프로덕션 출시 가능
- **결론: Google Play에서는 사실상 개인사업자 등록이 필수**

### 1.3 인앱결제가 있을 때

| 구분 | Apple | Google |
|------|-------|--------|
| **스토어 정책** | 개인 계정으로 인앱결제 앱 출시 자체는 가능 | 조직 계정 필요 (사업자등록 필수) |
| **한국 세법** | 매출 발생 시 사업자등록 의무 (개업일로부터 20일 이내) | 동일 |
| **통신판매업 신고** | 인앱결제 = 전자상거래 → **통신판매업 신고 필수** | 동일 |

### 1.4 중개 수수료를 받는 마켓플레이스 앱 (SafeWay Kids 해당)

**반드시 사업자등록 필요.** 이유:

1. **전자상거래법상 통신판매중개업자**에 해당
2. 중개 수수료 = 사업소득 → 사업자등록 의무
3. Google Play 조직 계정 요구 → 사업자등록증 필요
4. 통신판매업 신고 시 사업자등록번호 필수

## 2. 한국 법률상 요구사항

### 2.1 통신판매업 신고

| 항목 | 내용 |
|------|------|
| **신고 대상** | 전기통신매체를 통해 상거래를 중개하거나 판매하는 사업자 |
| **SafeWay Kids 해당 여부** | **해당** - 앱으로 학원 셔틀 서비스를 중개하고 수수료를 받으므로 |
| **면제 조건** | 6개월간 거래 20회 미만 AND 금액 1,200만원 미만 (소규모) |
| **필요 서류** | 사업자등록증 + 구매안전서비스 이용확인증 (PG사 가입 필요) |
| **신고 방법** | 정부24 온라인 신청 또는 관할 시/군/구청 방문 |
| **처리 기간** | 영업일 2~3일 |
| **비용** | 무료 |

### 2.2 부가통신사업자 신고

| 항목 | 내용 |
|------|------|
| **신고 대상** | 통신서비스에 컴퓨터 기능을 결합하여 부가가치 서비스를 제공하는 사업자 |
| **면제 조건** | **자본금 1억원 이하**인 부가통신사업자는 신고 면제 |
| **SafeWay Kids 해당 여부** | 초기에는 자본금 1억 이하이므로 **면제 가능성 높음** |
| **신고 방법** | 전자민원센터(emsit.go.kr) 또는 지역 전파관리소 |
| **주의** | 자본금이 1억을 초과하면 1개월 이내에 신고해야 함 |

### 2.3 위치기반서비스사업자 신고 ★ 매우 중요

| 항목 | 내용 |
|------|------|
| **신고 대상** | GPS, Wi-Fi, 셀타워 등을 이용해 개인의 위치정보를 수집/이용하는 서비스 |
| **SafeWay Kids 해당 여부** | **반드시 해당** - 차량 GPS 추적, 아동 위치 추적 기능 포함 |
| **미신고 시 처벌** | **3년 이하 징역 또는 3,000만원 이하 벌금** |
| **소상공인 유예** | 1개월간 신고 없이 운영 가능, 이후 반드시 신고 |
| **필요 서류** | 사업시설 증명, 위치정보 보호조치 관련 서류 |
| **신고 방법** | 전자민원센터(emsit.go.kr) 또는 방송통신위원회 |
| **처리 기간** | 최대 2주 |

**SafeWay Kids 특이사항:**
- 아동(14세 미만)의 위치정보를 수집하므로 **법정대리인(부모) 동의**가 반드시 필요
- 위치정보의 보호 및 이용 등에 관한 법률 준수 필수
- 위치정보 수집/이용 동의서 별도 필요

### 2.4 개인정보처리방침

| 항목 | 내용 |
|------|------|
| **법적 근거** | 개인정보 보호법 |
| **필수 여부** | **절대 필수** - Apple/Google 모두 요구, 한국법도 요구 |
| **Apple 요구** | 앱 스토어 등록 시 개인정보처리방침 URL 필수 제출 |
| **Google 요구** | 민감한 권한 사용 시 필수, 2024년부터 모든 앱에 권장 |
| **한국법 요구** | 개인정보를 처리하는 모든 사업자/개인은 개인정보처리방침 공개 의무 |

**SafeWay Kids 특이사항:**
- 아동 개인정보 처리 → 강화된 보호 조치 필요
- 위치정보 수집 → 별도의 위치정보 이용약관 필요
- 개인정보영향평가 검토 권장

## 3. 사업자 등록 없이 할 수 있는 범위

| 앱 유형 | 사업자등록 없이 가능? | 비고 |
|---------|----------------------|------|
| **완전 무료 앱 (수익 없음)** | Apple: 가능, Google: 개인계정 제약 있음 | Google은 조직 계정 권장 |
| **광고 수익만 있는 앱** | 법적으로 회색 지대 | 소액이면 기타소득 신고 가능하나, 반복적 수익 시 사업자등록 권장. 연 600만원 초과 시 사업자등록 의무 |
| **유료 앱 / 인앱 구독** | **불가능** | 매출 발생 = 사업자등록 의무 + 통신판매업 신고 |
| **중개 수수료 앱** | **불가능** | 사업자등록 + 통신판매업 + (위치서비스 시) 위치기반서비스 신고 |

### SafeWay Kids의 경우

SafeWay Kids는 학원 셔틀 서비스 중개 + GPS 위치 추적 + 수수료 수취 앱이므로:

- **사업자등록: 필수**
- **통신판매업 신고: 필수**
- **위치기반서비스사업자 신고: 필수**
- **부가통신사업자 신고: 자본금 1억 이하 시 면제**
- **개인정보처리방침: 필수**

## 4. 1인 개발자 앱 출시 실제 프로세스

### 4.1 한국 1인 개발자 앱 출시 사례

- **Flutter 앱 2개 출시 (비전공자):** 유튜브와 공식 문서로 학습 후 Android/iOS 동시 출시
- **가족 공유 앱 (40대 개발자):** 휴직 중 개발, 할일/일정/자산/가계부 공유 앱 출시
- **1인 앱 개발 연 1억 수익 사례:** OKKY 커뮤니티에 공유된 실제 수익 사례
- **공통적인 어려움:** Google Play 비공개 테스트 20명 모집이 가장 큰 허들로 언급

### 4.2 개인사업자 등록 절차 (매우 간편)

| 단계 | 내용 | 소요 시간 |
|------|------|----------|
| 1 | 홈택스(hometax.go.kr) 접속, 공동인증서 로그인 | 5분 |
| 2 | 사업자등록 신청 → 인적사항 입력 | 10분 |
| 3 | 업종코드 입력 (소프트웨어 개발: 722000) | 5분 |
| 4 | 사업장 주소 입력 (자택 가능) | 5분 |
| 5 | 임대차계약서 또는 등기부등본 첨부 | 5분 |
| 6 | 제출 → 처리 대기 | 1~3영업일 |

**비용: 무료 (0원)**  
**총 소요 시간: 온라인 신청 30분 + 처리 대기 1~3일**

### 4.3 전체 출시 프로세스 타임라인

```
[1일차] 개인사업자 등록 (홈택스 온라인, 무료)
         ↓ (1~3영업일 처리)
[3일차] 사업자등록증 발급
         ↓
[3일차] 통신판매업 신고 (정부24 온라인, 무료)
         ↓ (2~3영업일 처리)
[5일차] 통신판매업 신고증 발급
         ↓
[5일차] 위치기반서비스사업자 신고 (emsit.go.kr, 무료)
         ↓ (최대 2주 처리)
[19일차] 위치기반서비스 신고 완료
         ↓
[5일차~] Apple Developer Program 가입 (99 USD)
[5일차~] Google Play Console 조직 계정 생성 (25 USD)
         ↓
[동시진행] 앱 심사 제출
         - Apple: 통상 1~3일 심사
         - Google: 조직 계정은 바로 프로덕션 가능
         ↓
[약 3~4주] 전체 프로세스 완료, 앱 출시
```

### 4.4 비용 총정리

| 항목 | 비용 | 주기 |
|------|------|------|
| 개인사업자 등록 | 무료 | 1회 |
| 통신판매업 신고 | 무료 | 1회 |
| 위치기반서비스사업자 신고 | 무료 | 1회 |
| Apple Developer Program | ~₩139,000 (USD 99) | 연간 |
| Google Play Console | ~₩34,000 (USD 25) | 1회 |
| **합계 (첫 해)** | **~₩173,000** | |
| **합계 (이후 연간)** | **~₩139,000** (Apple 갱신) | |

## 5. SafeWay Kids 앱 출시를 위한 체크리스트

### 필수 (법적 의무)

- [ ] 개인사업자 등록 (홈택스)
- [ ] 통신판매업 신고 (정부24)
- [ ] 위치기반서비스사업자 신고 (emsit.go.kr)
- [ ] 개인정보처리방침 작성 및 웹 게시
- [ ] 위치정보 이용약관 작성
- [ ] 아동 개인정보 수집 시 법정대리인 동의 절차 구현
- [ ] Apple Developer Program 가입
- [ ] Google Play Console 조직 계정 생성

### 권장 (운영상 필요)

- [ ] PG사 가맹점 계약 (구매안전서비스 이용확인증 발급용)
- [ ] 부가통신사업자 신고 (자본금 1억 초과 시 필수)
- [ ] 서비스 이용약관 작성
- [ ] 전자상거래 표시사항 (사업자 정보, 통신판매업 신고번호 등) 앱/웹에 표시
- [ ] 사업자 통장 개설 (세금 관리용)

### 앱 심사 대비

- [ ] Apple: 개인정보처리방침 URL, 앱 스크린샷, 설명문
- [ ] Google: 데이터 안전 섹션 작성, 개인정보처리방침 URL
- [ ] 아동 대상 앱 관련 추가 정책 준수 (Apple: Kids Category, Google: Families Policy)

## 6. 핵심 결론

1. **SafeWay Kids는 사업자등록이 반드시 필요하다.** 중개 수수료 수취 + 위치정보 수집 + 인앱결제 = 사업자등록 불가피.

2. **개인사업자 등록은 매우 간편하다.** 홈택스에서 30분이면 신청 완료, 비용 0원, 1~3일 처리.

3. **Google Play는 조직 계정이 사실상 필수다.** 2024년 정책 변경으로 개인 계정의 신규 앱 등록이 극도로 어려워짐. 개인사업자도 조직 계정 생성 가능.

4. **위치기반서비스사업자 신고가 가장 중요한 법적 요건이다.** 미신고 시 형사처벌 가능(3년 이하 징역). 아동 위치정보 수집은 더욱 엄격.

5. **총 비용은 약 17만원(첫 해), 약 14만원(연간 갱신).** 법적 신고는 모두 무료.

6. **전체 프로세스 약 3~4주.** 위치기반서비스 신고 처리가 가장 오래 걸림(최대 2주).
